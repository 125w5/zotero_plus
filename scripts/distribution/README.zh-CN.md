# EasySch

运行安装程序，安装后双击 **EasySch** 即可使用。无需安装 Node.js、Python、Pandoc、LibreOffice 或配置环境变量。解压版直接运行文件夹内的 **EasySch.exe**，移动文件夹时保留整个目录。

支持 Windows 10/11 64 位。软件内置 PDF 阅读、论文素材整理、写作、DOCX/PPTX 导出所需的运行时和转换工具；不包含本地 AI 模型。AI、机翻和在线文献检索需要联网。

首次打开默认为日间白色系：白底深色文字、浅灰工作区、黑色 EasySch Logo。用户可以切换暗黑模式；主动修改的配色会保留。

此预配置版本已包含发行者提供的 DeepSeek、有道翻译和 easyScholar 接口。打开“工作台 → 设置 → 模型与翻译”，可以填写自己的接口地址、模型和密钥；“恢复内置接口”可切回默认配置。可用性取决于对应服务的网络、额度及授权。

首次启动使用独立的 `%LOCALAPPDATA%\EasySch\Profile` 与 `%LOCALAPPDATA%\EasySch\Library`。不会导入发行者的论文、笔记、聊天或个人账户。卸载只删除应用文件，保留这些研究数据；再次安装会继续使用。

本包内含发行者授权分发的 API 密钥，可被获得安装包的人提取；相关费用计入发行者账户。源代码包不含这些密钥。请勿把私人配置加入公开源码。

文件预览使用内置转换工具。Microsoft Word 和 PowerPoint 本身不随包附带；用户可以使用已有 Office 或其他兼容软件打开导出文档。

本预览版尚未进行代码签名。版本与测试限制见同目录发布报告。现有 Zotero 与其他软件的许可证和贡献者声明保留。
