# 研究工作台与底部输入栏验收

保留 Zotero/EasySch 单主程序、API-only、已有数据与嘉立创式论文装配布局。默认白色。本轮修改仅在本地，未提交或推送。

AI 可读取、检索、翻译原始文献，讨论证据、评估实验方案、整理主题和已有对象的展示顺序；不能代写、续写、润色或改写论文正文，不能生成图片或图表。旧研究资产、人工编辑和历史回复保留。顺序建议必须包含既有稳定 ID 的完整排列，通过人工确认后形成一次可撤销操作；内容、格式、所属章节和来源关系保持不变。

## 接口兼容性修复

真实请求曾两次返回 HTTP 200，但开启 `response_format=json_object` 后正文为空。单变量探测移除该参数后得到有效顺序 JSON；生产请求已修正，仅此网关使用提示词约束 JSON 并继续严格解析校验，DeepSeek 等服务保留原 JSON 模式。

修复后的真实验收没有修改请求内容或替换模型回复：`openai.goldgom.top`、`gpt-6-luna`、流式请求、HTTP 200、268 字符输出、`finish_reason=stop`；执行只返回现有 ID 的顺序及理由，没有调用写作或图片生成。
