- 图片证据使用同一份完整解释节点；展开时移到原图下，收起时回到标题区。保留富文本、来源和完整末尾，不再截断后增加“详细解读”折叠。
- 图片详情里的研究对话可以真正收起及恢复。修正 Fluent 把图标替换成长句、会话菜单被详情蒙层遮挡、强制展开覆盖收起事件的问题。保留输入草稿和会话归属。
- 原生笔记改用统一的软边界与阴影，保留搜索、排序、新建和编辑。笔记列表使用独立的不透明底层，避免玻璃工具栏透出其他面板的文字。没有改变笔记编辑器内容字体。
- 装配素材栏保留两行常驻搜索和工具，领域、第二关键词、模糊及已有分类筛选使用同一筛选弹层。常驻清空会清掉关键词、分类、排序、在线主题 ID 和主题词，不修改可行性方案或素材。
- 装配右栏、PPT 页面卡及普通操作使用共同圆角、边界、阴影和控件材质。主文档、缩略图与界面控件仍有明确区别。

- 领域弹层的 Escape 在本地消费；输入法取消不关闭弹层，也不会冒泡取消正在执行的可行性任务。

## 检索能力

- 研究领域使用共享宽泛预设，可搜索 OpenAlex 的真实研究主题或输入自定义领域；保存 topicID 与真实主题关键词。
- 本地素材缺少主题元数据时按真实主题词和内容匹配；有明确主题 ID 时尊重实际分类。
- 指定期刊入口直接提供“搜索更多期刊”，按期刊名称或 ISSN 查询真实目录并应用精确期刊 ID。
- TOP 与影响因子使用有来源的已存指标或用户配置的核验服务，不以引用量、期刊名称或 OpenAlex 引用均值冒充 JIF。核验保留来源与指标年份。
- 来源包含 OpenAlex、Semantic Scholar、arXiv、Crossref、Europe PMC；按实际提供者路由请求，不把不支持的筛选默默扩大。
- 年份支持不限、近一／三／五／十年和自定义起止年，校验年份并传到各来源。连续分页保留同一研究范围与筛选条件。

在线预检：OpenAlex 主题／期刊／日期、Crossref 日期、Europe PMC 日期成功。Semantic Scholar 当时返回 429，arXiv 当时连接超时；这两项没有被记为在线成功。其请求路由和日期参数另有受控测试。
