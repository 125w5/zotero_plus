# 阅读、素材与参考文献：结果入口整改

本轮保留原生 Zotero 主窗口、PDF Reader 和嘉立创式写作布局。修改现有入口和服务，未迁移或删除论文、用户素材、正文及方案版本。

## 实际复现

在日常 Zotero 主窗口打开“工具 → EasySch 科研工作台”，以及已有“论文装配 · 识别”项目：

- 没选论文、没有分析结果时仍显示“预览并保存笔记”。
- 素材详情直接展开长篇英文原文、“返回原文或数据”“加入当前模块”“检查来源更新”。
- 素材栏虽然已有折叠研究主题和类型，但真实日常素材尚未按主题归组。旧素材不会被静默重分类；需要查看并确认整理建议。
- 代码追踪确认原参考文献列表包含未解析 PDF 题录，并要求用户手动“检索这条参考文献”。

## 修改后的操作路径

| 入口 | 默认操作与结果 |
| --- | --- |
| 文献研究 | 无论文：选择论文并阅读；有论文：读懂这篇论文；输入问题：回答这个问题；PDF 选段：解释选段或回答选段问题。技能和提示词配置位于更多。 |
| 阅读结果 | 有真实分析记录后才显示预览并保存笔记。保存仍保留用户确认及撤销，原生笔记不被自动覆盖。 |
| 文献检索 | 收集参考文献，一次完成获取引用列表、题录匹配、去重、缓存；仅展示匹配到的论文。未找到、歧义和网络失败分阶段跳过，在折叠说明里列出数量与原因。 |
| 已找到的论文 | 获取并阅读；摘要、引用原文、来源链接及只保存题录折叠。列表加载不会批量下载或创建阅读标签。 |
| PDF Reader → 工具 → EasySch | 自动携带当前打开的附件及父论文，不再仅依赖后台文库选中项。 |
| 素材详情 | 中文概括和插入正文优先；原文、来源更新收进“核对原文与来源”。 |
| 写作正文 | 右侧补全当前段落，复用 Ctrl+Tab 的素材检索、选择、真实正文写入及撤销流程；选区润色和补证据仍只在选中后显示。 |
| 所有已有 AI 模板入口 | 输入框聚焦显示快捷功能，鼠标或 Tab 选择；模板编辑收进更多。 |

## 引用匹配约束

1. DOI 按完整标识符核对；arXiv 按编号及明确版本核对。
2. 没有标识符时，完整标题必须匹配，且作者和年份共同佐证。候选歧义直接跳过。
3. 每条结果保存原论文 ID、引用原文、登记来源或 PDF 附件；不把相似论文当引用。
4. Crossref 参考题录解析不要求存在摘要。非编号参考文献和无法可靠识别的 PDF 当前不猜测。
5. 单次最多匹配 150 条，双并发，约 90 秒启动预算；在途请求仍受服务超时约束。超限项在检索说明中列出。单条题录复用缓存，同一轮重复查询共用任务。
6. 缓存整组结果 24 小时，源附件大小或修改时间变化后重新收集。高级菜单可强制重新检索。
