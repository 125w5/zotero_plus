# EasySch 本轮界面与阅读修复验收（2026-09-18）

本报告区分源码实现、受控回复、原生客户端内程序测试、真实服务请求和实际桌面操作。原生测试中的 DOM 点击和构造 PDF 坐标不计作人工选句验收。

## 用户最新截图：论文选择器

入口：主页左侧「文献阅读」→「选择论文」。

已改为顶部搜索与全选、中间滚动列表、底部固定操作的对话框。复选框和标题在同一行；整行可点击，选中有中性灰底，长标题在行内换行。显示当前选择数量；列表焦点下 Ctrl+A 全选，搜索框内 Ctrl+A 保留文本全选。中文组词期间暂停筛选。只显示存在本地 PDF 的文献，不把仅有题录的条目当成已下载文献。

最终普通版重启后再次从主页打开对话框，实际鼠标全选 6 篇，再点击第一篇标题区域，计数降为 5，整行选择有效。搜索 `World` 得到 1 篇匹配、保留其他已选条目；在搜索框按 Ctrl+A，实际选中 `World` 文字，没有劫持为列表全选。1000×600 窗口下底部操作始终可见。测试最后取消对话框，没有提交批量 AI 分析。真实中文输入法组词尚未验证；普通注入中文文本不作为输入法验收。

## 本轮实现及验证边界

| 功能 | 操作入口与实现 | 已有验证 | 剩余限制 |
|---|---|---|---|
| 论文选择 | 文献阅读、组会 PPT 的论文选择器；整行选择、全选、固定按钮、本地 PDF 过滤 | 文献阅读实际桌面观察与点击；原生客户端 DOM 布局断言 | PPT 全部步骤尚未逐页完成桌面验收 |
| 模型名称 | 官方 DeepSeek 服务查询实际 `/models`；保留仍有效的用户选择，对失效型号使用服务实际提供的 flash | 真实接口返回 `deepseek-flash`、`deepseek-v4-pro`；受控测试验证合并并发请求和自定义服务不被改写 | 不能将用户猜测的 `deepseekv4.1flash` 写成已确认型号 |
| AI 状态 | 公用型号解析与进度文案；页面切换清理旧错误，整理弹层显示自身任务进度 | 源码与受控检查 | 尚不是全应用统一任务中心，未逐一走完所有 AI 入口 |
| 简洁学术问答 | 阅读侧栏对话先回答、默认 150–300 字、最多三节；后续疑问折叠 | 真实 PDF + 真实模型请求成功；最新策略原生回归真实请求约 5 秒完成 | 不能保证所有模型严格遵守字数；未把受控回复称为真实学术效果 |
| 结构化 AI 回复 | 阅读分析按摘录编号绑定原文，格式/来源校验失败最多一次重试；共创/PPT JSON 格式最多修复一次，截断结果不缓存 | Node 受控回复测试；原生测试实际执行一次阅读格式修复 | 其他任务仍可能因服务额度、超时或不合格输出失败；不会绕过证据校验 |
| Markdown 与引用 | 共用渲染器显示中文、列表、表格、KaTeX；同页链接优先按稳定证据 ID 定位 | 原生 DOM 验证中文、粗体、表格、公式及同页不同选区定位；未知链接不允许跳转 | 测试通过程序点击，尚未逐一用鼠标检查各个内容页面 |
| 侧栏返回 | 展开学术对话直接切到对话区域；「返回论文信息」及 Esc，切换其他原生侧栏项目退出对话聚焦 | 原生 DOM 验证；真实 PDF 前台点击展开后输入框可见，点击返回恢复信息/附件/分类/标签 | 其他侧栏入口仍需逐一检查；后续小窗口布局压缩头部、给消息区保留高度 |
| 原生批注 | PDF 划选→机翻→「保存高亮与笔记」；保存后同步已打开阅读器的批注 | 隔离文库实际写入、撤销，PDF 文件保留 | 测试选区坐标由代码构造；本轮尚未完成真实桌面划选与保存 |
| 句间关联 | PDF 选句右键「关联其他文献语句」；搜索另一篇已索引全文，或到另一篇划选终点 | 隔离文库保存双端原文/页码/位置/关系 | 真实桌面完整路径未验证；源 PDF 更新后的关联失效提示尚待补齐 |
| 完整图片 | 阅读侧栏「关联证据与论文图表」；图片确认可从完整页面重新裁切，并保存图片素材/来源证据 | 真实 World Model 论文 Fig.4 的新裁切范围已覆盖完整嵌图；两项边界回归通过 | 尚未从真实桌面完成提取→素材入库→回源。说明当前依据图注和正文，不能冒称模型已视觉理解图片 |
| 文献获取 | 搜集先保留题录/摘要；可仅保存摘要或获取公开 PDF，提供来源过滤、可选期刊黑名单 | 源码审查；PDF 文件头与 arXiv 标识处理受控测试 | 本轮真实联网下载全流程未验证；不得宣称所有站点下载正常 |
| 默认文件位置 | Zotero 管理附件，下载结果可「在文件夹中显示」；文献阅读卡片右键同样可定位 | 本地文件存在性检查与源码实现，已纳入最终构建 | 新增右键菜单的真实桌面定位路径尚未验证 |
| 下载复用 | 获取前检查本地附件，相同任务共用进行中的下载；只有实际文件存在才进入阅读候选 | 受控合同/原生候选过滤 | 真实重复下载无第二次传输尚未完成抓取验证 |
| 旧插件 | 已判为 `isCompatible === false` 的插件不启动，保留文件及数据 | 源码检查 | 未安装真实不兼容插件重现；不意味着可以识别所有行为冲突 |
| 素材及大纲全选 | 素材列表支持全选当前结果；大纲 Ctrl+A 选中模块，删除/撤销不删除底层来源 | 原有测试与本轮焦点逻辑检查 | 全应用所有列表、右键、双击与 IME 组合仍未逐项验收 |
