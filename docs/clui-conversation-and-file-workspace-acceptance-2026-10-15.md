## 文件归属、预览与拖动

- 每个会话独立保存文件选择、精选状态和表格工作表/范围。切换任务不等待旧模型，迟到回复与过期预览不能覆盖新会话。
- PPT 左栏同时显示当前汇报、项目与来源文件夹。论文详情、实际 Excel/CSV 单元格、图片和文本在右栏预览；提供返回入口。图片证据点击留在本地预览，只有明确定位才打开原论文。
- 文件“保存位置”读取真实 Zotero 条目路径，并可在系统文件夹显示；项目文件夹是文库中的归属关系，不擅自移动已有磁盘文件。
- 当前日常文库的数据目录为 `E:\workspace\zotero-main\.tools\research-native-data`。托管附件的具体路径由条目解析，通常在其 `storage\<附件 key>\` 下；界面显示每份文件的实际位置。

| 拖动对象与目标 | 实际效果 |
| --- | --- |
| 文件手柄 → 另一条对话 | 添加来源关联，保留原文件；不自动提交问题 |
| 文件 → 装配中的具体章节位置 | 读取实际内容，保存为一块完整素材并关联该位置；保留原始来源和人工正文 |
| 回答 → 装配中的具体位置 | 保存问题、回答与证据为研究笔记素材，插在原章节；不因页末换到下一主题 |
| 文件 → PPT 指定页 | 读取文件，记录该页证据及来源；保留人工讲稿 |
| 回答 → PPT 指定页 | 将回答加入该页讲稿，保留原讲稿和消息身份 |
| 回答 → PPT 空白处 | 不隐式新增幻灯片；明确新增页落点才增加一页 |
| 回答/证据 → 装配侧栏底部 | 显示同高叠卡；关闭后恢复原素材或详情栏 |

文字区域用于选择与复制，独立手柄或非文字区域用于拖动。来源关联移除不删除文库文件。读取文件期间改变工作表、范围或移除关联会拒绝旧结果；切换章节不会改变原落点。
