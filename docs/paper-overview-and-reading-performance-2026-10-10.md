# 论文首页与阅读性能整理

论文题录和 PDF 附件使用同一个 `paper-overview.mjs`：裁剪后的正文首页在最上方，真实标题、作者、期刊、年份、DOI 和已有 IF 来源放在预览下方，再显示摘要。缺失字段不显示占位标签。信息编辑入口与标题同一行；原生编辑区仍保留，通过“编辑”展开。

摘要优先读取父文献的 `abstractNote`，其次读取当前附件已经解析的文档中的显式 Abstract/摘要段落，最后检查本地全文缓存并复用一个 PDFWorker 任务。必须具有可靠的摘要标题和后续章节边界，才作为摘要显示；不把任意正文生成或伪装成摘要。全文缓存没有页面定位信息时，不伪造页码。

英文摘要默认尝试机器翻译，支持原文/中文切换。打开信息区的机器翻译失败或未配置时保留原文，不自动转为模型调用。已有快速翻译调用者默认保留原来的模型后备能力。

首页预览复用原来的 `assets.cover` 裁图结果，未修改页面选择、图片/公式提取或裁图边界。行内预览最多 360px 高且保留比例；悬停局部放大、单击大图、双击原文定位复用通用 `media-preview`。同一个可见预览重复悬停复用完整 PNG 读取任务。

原生信息/摘要/PDF 附件信息卡收为编辑时展开，首页和图片证据设置一次性的默认展开迁移。之后用户主动收起的偏好仍保留。信息栏使用一个入口定位首页；不为摘要和附件信息额外增加快捷栏按钮。

性能修改依据：

- 原概览在每次重绘时调用 `store.get()`，会复制全部文档状态；现在仅读取当前附件的索引和文档分支。
- IF/存储更新只比较小范围元数据，并更新元数据节点；对话流式更新不重建首页 DOM。
- 运行时快速翻译缓存设为 200，参考文献摘要任务设为 32，局部摘要任务和译文各设为 24；首页任务原来已有 16 的上限，继续保持。
- 文件指纹、翻译数据和已保存用户修改保持原样；限制仅作用于可重建的运行时缓存。

受控 Node 检查：13/13 通过（`paper-overview-data.test.mjs` 与 `overview-machine-translation.test.mjs`）。包含缺失 IF、真实显式摘要边界、父题录/已解析正文零 PDFWorker、并发 PDFWorker 复用、本地全文缓存优先、机翻专用模式零模型调用、既有默认模型后备行为。

语法及 diff 空白检查通过。主任务第三轮原生验收中，`researchReaderNavigationTest` 5/5 通过，`researchCompactSurfaceTest` 5/5 通过。后者还覆盖日历、装配和搜索等其他界面；这些结果分别记录，不与 Node 或真实联网统计混在一起。

首页用例使用隔离验收文库中实际 C-AMC PDF。文件 SHA-256 为 `249155d7ccd34c25ecd01d600d40257dbdf2c3c57dbdd9cdcf7cb3d5fa34f4f3`，裁剪首页来自 PDF 第 3 页，完整 PNG 为 1431×1999，缩略图为 402×561。受控路径响应复用这些有效的真实图片像素；导航位置、IF 和中文摘要回复仍为受控，未调用真实模型或期刊查询。

实际 Gecko 中已通过：悬停读取及解码原图、多次悬停共用一次完整 PNG 读取、单击大图、双击定位、中文/原文切换、IF 到达后保持图片节点、固定侧栏入口与顺序。320px 和 450px 侧栏均无横向溢出，实际预览约 257.70×358.83px，保留裁图比例且在 360px 高度上限内。报告位于隔离文库的 `reader-navigation-acceptance/report.json`；原生交互由测试事件驱动，不表示真人鼠标验收。

性能验收证明运行时缓存**条目数有上限**及特定任务/文件读取的复用，未测量峰值内存、长期堆增长、帧率或大规模文库耗时，不能据此报告内存降低百分比或整体“不卡”。单个未解析 PDF 的摘要恢复仍可能需要读取本地全文或执行一次 PDFWorker；缓存条目上限不等同于每次任务的字节内存上限。

只读交付检查与残余边界：

- 此子任务没有更改、删除或复制素材、原 PDF、用户摘要和笔记；仅组合显示并限制可重建缓存。
- 默认展开是版本 2 的一次性偏好迁移，后续折叠仍使用 Zotero 原生偏好保存。源码路径已核对；关闭程序再启动后的折叠偏好未在该 scoped 用例中独立验收。
- 父题录摘要优先，明确 Abstract/摘要恢复只扫描前六页的已解析段落并要求后续章节边界。非标准标题、文本抽取断行异常、图片式扫描摘要可能无法恢复；此时保持未显示，不编造摘要。当前真实 PDF UI 用例的摘要译文受控，不代表所有论文的真实机翻质量通过。
- 机翻未配置或失败会保留原文；含中文的摘要与超过 5000 字符的摘要不会自动翻译。真实翻译服务、真实 IF 查询及复杂摘要公式排版不属于本次 scoped 联网/视觉验收。

本子任务未构建、启动、提交或推送；上述原生运行由主任务完成。

## 本轮信息与摘要补充（尚待新的原生验收）

总览现在读取 `getUsedFields(true)` 中全部已有书目字段，结合原生 `ItemFields` 标签显示刊物/会议、出版社、卷期页、完整日期、DOI、ISSN、URL 及其他已保存字段；空值省略。作者使用真实 `creatorTypeID` 的原生角色标签分组，保留完整姓名与机构名称，不用省略版 describe 覆盖。已有题目优先于解析题目。IF 仍只显示已有真实数值、年度与来源。

原生信息字段和作者编辑能力通过总览标题行的“编辑”使用：保留原 pane 在同一个父节点中，将它临时显示为编辑弹层，而不是在阅读区展开第二张信息卡。关闭、Esc、切换文献或销毁窗口恢复隐藏；标签等低频原生信息同样使用此弹层。“附件”原生面板及导航入口隐藏，附件对象、文件、关联和其他页面的访问路径不删除。

摘要默认显示源句简述：在实际摘要中提取开头与已有实验/结果句，较长句在 260 字符处省略；它是摘录，不是模型生成的总结。展开可读取完整摘要；展开/收起与语言切换共用同一份数据，切换语言保留展开状态。关键词仅从已有标签、明确的 Index Terms/Keywords 以及文字中实际出现的缩写匹配，使用安全文本节点高亮；没有出现的词不会插入摘要。

本轮 Node 检查 22/22 通过（概览数据 13、机器翻译边界 4、阅读导航 5），覆盖完整原生字段/角色保留、未知值省略、真实句摘录与小数、关键词精确匹配、附件对象保留、文件变化失效及过期响应。新增/更新原生用例覆盖元数据编辑弹层、全部真实字段、摘要展开与术语高亮、原文/中文切换不重复翻译、附件隐藏后真实 PDF 仍存在；本轮尚未执行它们，不能沿用上一轮通过结果宣称新功能已实机通过。

限制：简述是本地规则选择的源句，不能保证始终选到作者最重要的结论；完整摘要保留供核对。标签缺失或摘要只有普通文字时，高亮可能较少；不会调用模型猜词。摘要恢复与真实机翻服务的既有边界不变。本轮没有改变图片/公式提取、裁图、材料数据或模型传输，也没有新增后台模型调用。
