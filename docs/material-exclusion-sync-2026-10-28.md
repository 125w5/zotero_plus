# 素材排除标记：已打开页面的局部同步

日期：2026-10-28。

“划掉”仍以现存、未删除且带排除标签的原生批注为准。旁路选句数据用于精确定位，单独存在时不会排除任何内容。删除原生标记后，素材从原始缓存恢复；原始 PDF 解析缓存和人工正文不修改。

## 通知路径

新增 `shared/material-exclusion-events.mjs`，通过 `manuscripts.onMaterialExclusionsChanged` 提供按附件订阅的专用事件。只有素材页或装配素材视图打开时才注册原生 `item`／`item-tag` 与存储监听；最后一个视图取消订阅后移除监听、定时器和附件状态。

```js
const off = E.manuscripts.onMaterialExclusionsChanged(change => {
  // change = {reason: 'material-exclusions', attachmentIDs: [attachmentID]}
}, {attachmentIDs: [attachmentID]});
off.update([anotherAttachmentID]);
off();
```

首次异步加载批注后回调一次，使同步首屏与原生批注数据一致。后续同附件 30 毫秒内的通知合并，并比较真实排除快照；内容相同时不重画。普通批注最多检查它所在的已关注 PDF，不会作为排除事件通知界面。

存储监听先核对准确的 `changedBranches`，仅在 `materialExclusionQuotes` 改变时读取该分支，再按变化键提取附件 ID。普通输入、笔记和其他会话的保存不读取排除数据、不检查附件批注。

原生标记快照保留数值 annotation ID 与附件的短期映射，因此 `erase()` 已卸载条目时仍能找到受影响 PDF。映射仅覆盖已打开视图关注的附件；切换范围或关闭页面时释放。全局资产通知、文件夹扫描与全文库索引不参与此路径。

## 页面与 AI 的一致性

- 装配仅刷新素材列表及相关的当前素材详情，不重画正文画布、不移动正文光标、不保存项目。
- 素材库仅更新列表、数量和当前选段，保留问题输入和方案编辑器。
- 已完全排除的材料仍按原始范围保留附件订阅，删除标记即可恢复，不能从过滤后的空列表推导订阅范围。
- 过滤行是独立展示视图。详情重命名和手动说明保存仍写入原项目素材记录，完整原文不会被过滤文本覆盖。
- 素材说明生成、说明润色、来源问答、方案和写作均使用允许的来源范围。全部被排除时不调用模型。
- 问答、方案、方案局部修改和说明润色在返回时复核排除签名，拒绝中途已改变依据的旧响应。新可行性方案的有效性包含其来源排除签名。
- 安全说明使用对应文本的缓存；再次显示相同安全说明不重新生成，也不再次加载原生批注。
