## 显示与操作

- 装配“文字工具”靠左，视图和侧栏开关归在右侧；保留展开/收起、固定、字体段落、插入、查找替换和快捷键。折叠工具组保持横向滚动，不挤压正文。
- 首页长标题限制为两行，正确收缩、换行，更多菜单仍可弹出，不靠裁掉整个卡片解决溢出。
- 顶部固定任务条使用与阅读/写作页面相同的字体及明暗色变量，保留菜单、窗口按钮和真实任务计数。
- 语料库沿用共享字体、圆角、控制样式与卡片阴影。搜索/章节/清空、数量与操作分层；支持全选筛选结果（包括首批以外的条目），切换筛选不丢选择。首批构建60张卡，继续显示可看其余完整语料；长原文只在展开时创建DOM，全文始终保留。
- 新建论文不覆盖手填关键词。草稿输入保留IME组合输入；本地草稿与延迟分支保存避免每键全库复制，执行评估等动作前统一同步。
- 准备文献可批量选择。快捷检索和整理在可行性页真实执行。匹配章节会展示已关联、可匹配和待明确用途的结果，支持导入准备区原文并定位模块；未知用途留在库内，不硬塞引言。

## 数据与性能

- storage.updateBranch 与全库更新共用原子保存队列，修改分支在队列中读取，返回快照仍隔离；旧并发保存不会覆盖新内容。
- 检索批量读取指标分支，移除逐候选的全状态克隆。服务层检索总预算60秒，取消与过期响应有明确边界，保留已验证的部分结果。
- PDF候选检查真实内容前缀，不把OA标记或URL当成下载成功。6路探测、单地址12秒，瞬态失败15秒后可重试；下载使用独立后台传输，不被arXiv检索队列挡住。
- 下载后登记真实附件和目标文件夹；重复点击复用附件。服务器返回HTML、验证页或无效文件时报告错误，不保存为PDF。
- 可行性准备时建立项目语料库，复制所选真实论文的完整章节与来源锚点、版本；排除纯AI讨论。原文派生的完整章节保留，批量一次保存，不逐段反复写全库。已有语料与人工修改不自动覆盖。
- 已完成图片说明不因模型、提示词、提取器或选择算法升级自动重建。实际PDF改变才重新核对来源；手动重新解读仍保留入口。速读文字继续使用原有持久缓存。

- 默认方案走 GPT-6.1 Sol / high，装配写作候选及全文评估走 Sol / xhigh；实际请求体包含 reasoning_effort。明确手选和其他自定义服务保留。
- 自动模型菜单不再错误地把第一项当成手选，增加“极高”。图片与低价翻译维持原配置。
- 创新分析提示词要求候选路线、最近邻差异、证据缺口与可证伪的最低成本验证，避免用缺少定义替代整份分析；不将候选创新冒充已证明的成果。
