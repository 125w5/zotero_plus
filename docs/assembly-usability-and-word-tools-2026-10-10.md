# 装配、共享对话与手工编辑验收

此文件记录较早的装配改造阶段。后续首页/摘要、公式、字号与富文本导出、图片尺寸、性能和实际 provider 验收，以 [最新验收记录](reader-and-editor-final-acceptance-2026-10-10.md) 为准；下列旧阶段限制与计数没有覆盖后续实现。

本轮保留嘉立创式外层布局及默认白色。视觉参考用户提供的 Word 工具栏：常用操作按撤销、文字、上下标/颜色、段落分组；消息与底部输入共用阅读宽度；次要信息折叠。WisPaper、ClawsGO 的固定输入与上下文操作、Flowing 的次要信息折叠用于交互组织，没有嵌入其整页界面。

## 实际行为

- 阅读器学术对话、悬浮 Logo、工作台和装配共用会话。默认按论文或项目区分；可显式继承历史。空会话、输入草稿、附件和模型设置不会独立创建历史，首次发送用户消息才保存。
- 底部输入保持固定；左侧新建/切换会话，右侧仅显示回答实际引用的来源。不会展示模型思考。外部单击淡化，不拦截原处功能；双击收起。
- 删除装饰性的四步骤条。章节视图显示实际内容，可拖动章节、排序模块、跨章节移动；来源核查按真实素材归组并列出每处使用位置，支持已引用、待核对、未引用和全部筛选。
- 切换左栏后继续保留右侧已选素材。搜索历史保留；高级筛选收在搜索入口。章节支持 Ctrl 多选、Shift 连选和已有键盘操作。
- 常用手工文字工具支持字体、加粗、斜体、下划线、上下标、颜色、清除格式；正文选区保持。标题/列表的行内格式尚未具备完整导出路径，因此本轮新增工具栏不会对它们提供仅前台有效的行内格式；段落四种对齐支持正文、标题和列表，并持久化与导出。
- 素材内 Enter 保持原框换行；正文空白双击插入段落；Delete/Backspace 仅删除空实例，非空末尾 Delete 不删除框。删除可撤销，来源素材保留。
- 公式编辑支持真实 LaTeX 预览与原文公式选择。明确区分保存的 LaTeX 与 PDF 原式图片，不猜测残缺 OCR。上下标等数学排版由 KaTeX 处理。
- 素材说明可以手工增加文字、公式、图片、表格。AI 基于原始素材润色说明时返回待审草稿，并检查数字未被改写；不会修改原文、PDF 位置或论文正文。
- 正文、素材详情及对话媒体统一悬停局部放大、单击全屏预览、双击定位来源或编辑。可编辑表格在题行保留小预览入口，单元格输入与行列拖动不被抢走。重绘清理预览监听与计时器。
- 浮动 Logo 使用文章内边界吸附；左右栏靠近文章的边缘为吸附边界。停靠时隐藏外部 Logo，拖出对话栏会一起迁移 Logo。
- 工具区和底部使用浅色玻璃；正文纸张、侧栏托盘、素材卡、原文托盘与说明卡采用不同边界与阴影层次。灰色 SVG 与对齐的按钮热区提供悬停、按下、选区反馈，尊重减少动画设置。

## 验证

- Node：77 项通过（共享会话、Pi 工具桥、附件、来源导航、素材说明、正文媒体和段落格式；没有重复计数）。
- DOCX：2 项实际导出/重读检查通过，正文、标题和列表对齐保留，旧块不强制更改模板默认对齐。
- 原生 Gecko：首轮 41/43；两项失败来自测试辅助函数返回布尔值却按 KeyboardEvent 读取。修正辅助函数后，实际换行、空框删除、撤销、内容与来源断言均通过。
- 更新后六组原生检查 48/49，唯一失败来自测试将规范化来源锚点与未规范化输入做全对象相等比较。已改为精确核对附件、页码、完整区域、原文与输入不变；产品没有为了适配测试而修改来源。
- 另修复学术侧栏 XPCOM 全局缺少 `clearTimeout` 的错误，销毁后取消计时器、任务和订阅，阻止迟到结果写入旧栏。
- 原生日志发现 Zotero 标签栏首次渲染前接收通知的初始化竞态：将空颜色表从数组改为其契约要求的 Map，并增加首次渲染前通知检查。

最终针对性复验：正文媒体 **5/5**，标签初始化 **1/1**。合并此前已通过的 44 项，原生共 **50 项独立检查通过**，不是声称重新完整运行了所有套件。标签测试初次命令误用 `tagsBox` 大小写，资源包实际为 `tagsbox`；修正命令后真正执行并通过。

另外为关闭窗口时已移除的标签容器增加空值保护，避免 `tagSelectorShown()` 在销毁期间读取空容器；通过语法检查。原生测试销毁期间仍有本地化缺失和数据库关闭时的后台写入日志，这些没有计入成功断言，也不能据此声称整个应用无错误。

不带 `-Test` 的日常版本构建成功，并使用 `research-native-profile` / `research-native-data` 重新启动。桌面窗口激活被工具的用户输入保护拒绝；后续只读画面不是目标应用，因此没有用它当作实际视觉证据，也没有继续注入鼠标操作。原生上述检查为真实 Gecko DOM 与受控事件，不能替代本轮未完成的真实鼠标视觉验收。
