# EasySch 设计、操作与工程交接手册

实现快照：2026-10-27。正文为中文，按当前源码编写。

## 使用与分发

打开 `index.html`。它是独立 HTML，包含全部正文、样式、脚本、结构示意、色票和两张隔离原生验收截图；无需服务器、CDN、字体下载或模型连接。单独复制这一个文件即可阅读和分享。

全文共 44 章、204 项操作说明，关联 128 个源码文件。目录可以定位章节，搜索可查功能名、操作、变量、路径与字体等词；Ctrl+K 聚焦搜索，Esc 清除。文档提供操作、设计与开发三条阅读路线。

“打印 / PDF”调用浏览器打印，输出前会展开源码说明。源码索引可在页面内下载。页面交互只演示设计规则，不会连接或修改 Zotero。

建议维护者保留整个目录。正文中的源码链接依赖它位于仓库 `docs/handoff-2026-10-27/` 的相对位置；单独分享 HTML 后，源码路径仍可阅读和检索，但链接不再指向接收者本地仓库。

## 文件如何维护

| 文件 | 用途 |
| --- | --- |
| `index.html` | 最终独立文档，可单独分发 |
| `data/workspace.json` | 文库、对话、检索、语料库和设置 |
| `data/reader.json` | 阅读器、翻译、速读、图表、引用与批注 |
| `data/writing-ppt.json` | 可行性、装配、PPT 和工程交接 |
| `data/design-system.json` | 设计依据、视觉规范和迁移方法 |
| `handbook.css` | 手册自身样式，不是产品覆盖样式 |
| `handbook.js` | 手册交互，独立于产品与服务 |
| `build-handbook.mjs` | 合并内容、内嵌资源、核对源码并生成最终文档 |
| `source-index.json` | 章节—源码关系、行号和源码 SHA-256 |
| `build-report.json` | 生成规模、缺失源码、资源数量 |
| `check-handbook.mjs` | 不联网的 DOM 与结构检查 |
| `qa-report.json` | 本次文档检查结果与边界 |

从仓库根目录重新生成：

```powershell
node --check docs/handoff-2026-10-27/build-handbook.mjs
node --check docs/handoff-2026-10-27/handbook.js
node docs/handoff-2026-10-27/build-handbook.mjs
```

生成器仅使用 Node 内置模块。它读取上述 JSON、相关源码和指定的隔离测试截图，不读取日常文库、密码管理器或用户配置。若截图目录在新电脑不存在，会保留正文并在生成输出中说明未包含截图；如果直接复制已有 `index.html`，内嵌截图完整保留。

更新某章时，先核对真实控制器、最终加载的 CSS 和保存服务；更改 JSON 后重新生成。代码变化可能使行号和 SHA-256 失效，应重新核对，而不是只改日期。每项操作说明应包含触发、结果、保存范围和状态，不能只写按钮名称。

```powershell
$env:HANDBOOK_QA_MODULES='你的测试依赖目录/node_modules'
node docs/handoff-2026-10-27/check-handbook.mjs
```

内置浏览器的 URL 策略拒绝打开本地文件，未使用替代浏览器路径绕过。本轮没有完成浏览器画面复验；实际字体命中、桌面与窄屏换行、玻璃合成、表格滚动和打印分页需要接收者在浏览器中确认。CSS 语法另经静态解析，无顶层解析错误。

手册记录的原生测试来自此前产品验收；本次写文档未启动或构建产品，未改变日常文库、论文、设置或进程。
