# PPT 取材范围与阅读器结果反馈

2026-09-08，本次沿用 Zotero 原生阅读器和上下文菜单。

## 使用入口

- 组会 PPT → 选择材料 →「这次汇报只取哪些内容？」：整篇、指定 PDF 页码、仅高亮与批注。多论文分别填写页码，如 `2–5, 8`，页码从 PDF 文件第一页计数。
- 阅读器选中文字 →「用这段原文生成 PPT」：创建只包含该选区的新草稿，仍可在材料步骤切换范围。
- 选区工具条或文字选区右键菜单 → 翻译／解释／专业术语：结果卡片留在阅读器右下角，显示原文、证据与回跳；关闭选区不关闭结果。

## 范围保证

分页范围在本地取材时过滤正文和图表，窄范围不额外加入摘要。选区和批注模式不加入其他页面图片。空范围、越界页码或空批注明确报错，不回退到全文。修改范围后必须重新读取材料、确认大纲。AUTO 对部分材料规划 3–8 页专题大纲，实际模型输出仍需用户确认。

翻译请求不携带之前整篇论文的 AI 分析。结果卡片提供失败重试，来源使用附件 ID 与 PDF 页码定位。保存的结果仍在原有研究记录中，前台无需切换到工作台才能看到。

## 验证

- Node：范围解析、真实取材边界、无选区不显示右键操作、选区请求排除旧分析，以及已有产物测试通过。
- 原生 Zotero：10/10 通过，2 项可选远程服务测试未启用。覆盖四个 PPT 入口、页码取材、六步编辑、可编辑示意图、单页预览、翻译按钮、原文证据、选区消失后结果保留、PDF 渲染与 DOCX 定位。
- UI 测试使用真实 PDF 和受控模型回复；截图中的译文为明确标注的测试回复，不作为真实 DeepSeek 翻译质量验证。

## 当前限制

- 指定范围按页码或选段，不自动猜测论文的章节边界。
- 批注模式使用全部已有高亮／批注文字，尚未提供逐条勾选。
- 结果卡片随当前阅读器保留；关闭附件后可从已有研究记录查看结果，不自动恢复浮层。
- 本轮没有重新评测完整论文生成的 PPT 视觉质量，也没有调用远程服务验证翻译质量。
