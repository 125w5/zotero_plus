# 论文选择、空证据与右键翻译修复

2026-09-08

## 根因与修改

用户当前的两个 PPT 草稿均没有选中论文，最近失败草稿的证据列表也为空，却已经进入正文生成。这会让模型在没有材料时返回无法绑定引用的“论文事实”。原来的界面只有读取 Zotero 当前选中项，缺少工作流内的论文选择器。

- 在材料步骤新增「选择论文」，可搜索并勾选个人文库中的一篇或多篇论文；确认后显示所选列表，多篇默认使用综述模板。一次最多 12 篇。
- 空材料不得请求模型；旧的空材料草稿打开后回到第 1 步。已有页面不直接删除。
- 多论文按附件轮流分配上下文，避免第一篇占完预算。
- 模型摘录编号自动绑定连续原文；修复重试后仍无法核对的条目改为明确的「待验证观点」，不补造引文，也不标成已验证事实。修改页可查看待核对提醒。
- 右键操作合并为一组原生菜单项。翻译卡片移到阅读器右上方，先显示进度，再显示回复；重复点击不会替换正在等待的卡片。原文、证据和定位按钮保留。
- PPT 页顶部显示本次汇报选中的论文数，不再使用独立研究页的空选择提示误导用户。

## 验证结果

- Node 16 项通过：包含空材料禁止请求模型、摘录缺失后的明确降级、多论文公平取材和已有产物导出。
- 最新桌面回归 10/10 通过：实际多选框选中两篇条目、六步流程、生成编辑、原生右键菜单、等待远程结果时先显示卡片、回复后显示证据，以及 PDF、DOCX 回归。
- 真实 DeepSeek 单页重新生成成功，未命中缓存，产生 3 条有原文摘录的事实条目；随后整套既有幻灯片成功渲染。其他页面复用了已有结果，不表示本轮重新生成了全部页面。
- 前台多论文流程使用两篇测试条目和受控模型回复；它验证选择和数据流，不是多篇真实论文综述质量评测。翻译截图同样使用明确标注的受控回复，以验证延迟、显示与定位。
