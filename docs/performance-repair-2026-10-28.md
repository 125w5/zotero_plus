# 阅读、批注与素材性能修复（2026-10-28）

本轮按用户要求先处理卡顿，暂不制作安装包。保留现有布局、功能、文库、人工正文和已生成内容；验收使用独立测试文库与合成大缓存，不读取日常论文正文或密钥，不调用付费模型。

## 处理的实际开销

### 小保存不再深拷贝整份工作区

原工作区文件约 60.8 MB。原来的普通 `store.update()` 会先复制全部工作区，再把全文和图片缓存重新序列化；读取设置也存在间接复制整库的路径。

现在事务按修改路径复制，未变化分支及条目复用已经编码的 UTF-8 片段。读取设置、当前论文、引用缓存和图片索引时只读取对应分支。提交仍使用同一个 `workspace.json` 原子写入，并保留 `.tmp`、`.bak` 和串行队列；`await update()` 仍表示已经成功写盘。失败事务不发布状态，后续保存可以继续。

事务同时保留既有 JavaScript 赋值行为：`const row = state[id] ||= {}` 后通过 `row` 追加的首次内容必须保存。外部对象在事务结束时隔离，之后修改保留的引用不会偷偷修改存储。

整个文件仍需要组装与写盘，成本没有变成常数时间；变化条目需要编码，首次保存还需要初始化缓存。启动后的空闲准备会预编码并冻结可共享的缓存，但时间片只在条目之间检查，单个大文档仍可能超过目标时间片，不能宣称严格的 8 ms 上限。原有 `get()` 继续返回独立副本；只读共享接口返回冻结快照。

### 笔记不再重复同步保存和重建

同一笔记重复打开时复用编辑器与 iframe。切换或回退保留唯一必要的销毁保存，移除先保存、再销毁、再移除造成的重复同步序列化。回退先恢复已缓存的列表，随后刷新；隐藏的笔记列表不再每秒轮询等待显示。

笔记链接按分支版本建立索引，页码排序只读取一次链接分支。同一笔记连续通知合并，旧文库中隐藏的 Context 不刷新当前列表。

### 批注不再引起整套资料栏重绘

普通 note/annotation 保存不再失效整个文件夹缓存或重绑定资料栏。真实附件变动合并处理，并只失效相关文件夹。研究对话按当前会话订阅，其他论文的消息不重绘当前正文；本地输入保留正文节点与会话 ID。

检索和 PPT 初始化不再扫描全库每个 PDF。研究对话实际需要候选资料时才扫描，切走后迟到结果不会加载隐藏页面的论文预览。

回归中的调用次数：60 次普通保存造成的 `manuscriptLibrary` 读取从 60 次降至 0 次；连续通知的文件夹扫描从 1 次降至 0 次；5 次间隔 135 ms 的批注保存所触发扫描从 5 次降至 0 次。这些是确定调用次数测试，不是实际整机帧率测量。

### 阅读准备与整理素材分开调度

先让阅读器显示，再开始自动准备。恢复多个标签时只准备当前阅读论文，其他标签真正打开时再准备。同文件签名已完成的图表索引、译文和速读直接复用，不因工具栏构建或附件元数据通知重新整理。

素材队列按篇准入，轮到该篇时才启动其图片和译文准备；优先当前阅读论文，篇间让出事件循环。取消排队立即移除，错误、成功和取消都会关闭进度任务。已产生的文字与图片缓存保留，样式更新不会重跑生成。

详细准备策略与 80 项相关回归见 [阅读准备修复记录](reader-performance-repair-2026-10-28.md)。首次无缓存的论文仍需要提取和生成；正在运行的单篇任务继续受原有取消与超时机制约束。

## “划掉”的统一含义

“划掉”表示该原文范围不进入自动素材和 AI 写作证据。PDF 仍保留，删除原生划掉标记后恢复可用。普通涂画不受影响。

原生保存为带 `easysch:material-exclude` 标签的 ink 标记，并将精确选中文字和位置保存在独立索引中；可见批注内容不塞内部元数据。只有对应原生标记仍存在时，排除索引才有效。

自动素材按连续剩余片段展示，不把被截断来源拼成伪造引文；人工编辑素材与正文保留。送往 AI 前重新检查排除来源，避免旧候选或在途请求重新带入已经划掉的内容。

已打开的素材视图通过附件级事件更新，只检查所关注的 PDF，合并同附件通知；不恢复全目录扫描。

## 顶部进度条

沿用共享表面、字体、阴影与明暗主题变量。进度区域最高宽度 660 px、高度 32 px，轨道加粗到 12 px；右侧窗口按钮保留原位置与命中区域。窄窗口和减少动态效果设置继续生效。

## 验收方法和证据

- Node 回归覆盖事务语义、笔记复用、通知范围、缓存复用、队列取消与素材排除。
- Gecko 原生测试使用真实 `IOUtils` 原子写盘，独立 32 MiB 合成缓存和原生事件循环心跳。
- PDF 验收要求真实来源拖选、浮层坐标点击、原生 AnnotationManager、数据库记录、PDF 页面绘制和关闭重开；按钮回调通过不能代替这条链路。
- 明暗外观通过真实 Gecko `computedStyle`、布局尺寸与截图检查。外观受控夹具不代表在线检索或模型效果验收。

最终源码在 60 MiB 合成工作区的暖缓存基准中，读取设置中位耗时从 59.13 ms 降到 0.02 ms，小笔记链接保存从 124.42 ms 降到 9.26 ms。该基准实际分配 UTF-8 字节并组装写入数据，但仅模拟异步写入边界，没有计实际磁盘延迟，也不等于实际文库或全应用帧率。真实 Gecko 与原子磁盘测试另行报告。
