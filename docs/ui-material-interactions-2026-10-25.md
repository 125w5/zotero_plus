# 2026-10-25 界面材质与交互修整

本轮对应七张截图中的控件、检索、对话和图片证据问题。保留现有页面框架及已有功能，不用设计稿替换实际页面，不迁移或清理日常文库、素材、正文、方案或会话。

## 显示调整

- 检索内容使用可用列宽；输入条件集中在一个面板，筛选与保存位置使用浅色分区。结果使用独立卡片、柔和边界及轻阴影，减少连续横线。
- PPT 顶部草稿选择和操作按钮分别排列，补齐间距与窄屏换行。大纲保留标题、讲述任务、排序、插入和删除；宽屏使用两列卡片，空间不足时恢复一列。
- 可行性页面扩大可用宽度，统一输入区、资源区、结果面板、按钮与步骤条的材质。步骤条统一使用 14px 外圆角、8px 控件圆角和 50px 最小高度，各页面保留自身步骤数及跳转条件。
- 界面继续使用上传参考中的字体栈：Bahnschrift、Noto Sans SC、Microsoft YaHei UI、PingFang SC。图片摘要与详细解读也使用该字体栈；论文原始图注、公式、文稿和幻灯片内容保留各自排版。
- 研究对话正文与输入区使用相同的可读宽度；选中附件使用完整的单行横向滚动区域，预览、移除及拖动保持可用，不再被文本框挤压截断。
- 图片证据的简要说明只在标题区显示一次。展开图片后使用共同的“详细解读”控件；原文来源、完整解释和展开状态保留。打开图片仍查看图片详情，通过明确的来源按钮定位原文。

## 交互修复

- 第二左栏新建对话后可立即命名；双击名称、F2、右键菜单均可重命名。人工命名的空会话会保存，首次提问不会覆盖人工名称。空白名称不提交，输入法组合期间的 Esc 不取消名称。
- 菜单支持键盘操作、Tab 关闭和 Esc 返回原按钮；菜单 Esc 不再冒泡关闭研究对话。
- 原生标签栏“+”为文献检索、论文装配、组会 PPT 创建独立页面。原有左侧功能导航仍复用原工作区，保留原页面关键词、未提交内容和会话。
- 修复检索翻页哨兵在请求繁忙时提前触发后不再恢复的问题。首次请求 40 篇，后续继续使用来源提供的分页及游标；下滑与“加载更多论文”均可继续。实际篇数仍受来源和筛选结果影响。
- 后续页暂时为空时允许继续，失败后显示明确的重试操作，避免反复自动重试。保留已加载卡片、选中项及已展开的来源详情。
- 离开检索页取消过期检索和翻译；返回后先恢复检索状态，再应用研究方向。移除所有查询共用的一秒等待；同词新检索不必等待已经取消的请求。摘要详细排版延后到用户展开时执行。
