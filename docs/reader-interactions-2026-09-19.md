# 阅读器与笔记交互整改（2026-09-19）

保留原有单主程序、PDF 阅读器、日常文库与 API-only 架构。以下区分真实前台操作、原生客户端程序测试、受控测试和真实服务调用，不将它们合并为“全部通过”。

## 已实现

- 标签栏空白右键打开页面菜单，新增页使用居中的细灰色加号；工作台导航增加图标与缩进。
- 左下常驻月历，日期点击原位展开待办；未完成红色、完成绿色、过期未完成黄色。支持勾选、双击编辑与右键操作。
- 首页预览移除重复的“打开 PDF”按钮。图片证据及本文参考文献使用现有右栏。
- 修复图片证据图标存在但内容消失：栏位重排误选了附件笔记内部的 `related-box`，现在只定位直接子栏。侧栏图标展开目标栏。
- PDF 选区 Delete / 划掉按钮 / 选区右键添加红色删除线，不修改底层 PDF；输入框与输入法组词状态不触发。
- 高亮、下划线立即作用于当前选区；已选标注可转换类型。
- 保存选区笔记后打开刚保存的笔记；关联笔记回收/恢复同步标记，共用标记仍被其他笔记使用时保留。
- 关联批注支持悬停摘要、中文机翻及双击打开笔记。用户评论与自动译文采用不同字号、颜色。
- 图片证据中“更多 → 图片与解读保存为笔记”保存完整提取矩形、现有中文解读和来源，打开新笔记。
- 笔记顶部“＋ 插入”支持图片、Excel/CSV、原生表格与公式；搜索旁支持时间/页码排序。
- 修复笔记表格附近插图的光标越界；删除或撤销后迟到的批注图片更新不恢复标记。
- 同文件图片整理按指纹、解析版本和分析版本复用；复用仍补齐附件来源关联，不覆盖用户修改。
- 本文参考文献先保留全部原始题录，未匹配项仍显示。标题点击定位本篇引用，悬停机翻；匹配后按需获取公开全文。
- 文献选择对话框修正列表与底部按钮的伸缩约束，默认 820×520、最小 600×360；仅保留标题、作者、年份，防止主文库的信息列将题目挤没，补充灰色选中反馈。
- 前台发现并修复“＋ 插入 → 创建表格/公式”无效：改用原生编辑器实际支持的命令协议。
- 构建链纳入 reader/note-editor 的本地源码修改，避免只复用子模块旧提交缓存。

## 尚未完成的前台验收与边界

- 完整清单仍未全部验收，尤其真实中文输入法、跨页一次撤销、复杂分式/旋转页、分屏第二视图悬停、Excel 文件选择、多种窗口尺寸的选择器稳定性。
- 删除线是 Zotero 红色 ink 标记，保留 PDF 原文件。跨页可能生成多条标记，撤销次数按标记计算。
- 图片提取采用已有识别边界，不能保证所有扫描论文或组合子图自动裁切完美；保留整页核对与调整裁切入口。
- 原生笔记保存 TeX 公式；不能据此声称可从任意 PDF 公式无损恢复 LaTeX。
- 本轮未验证真实模型生成 AI 笔记、参考文献全流程联网下载；未知题录不会伪装成已下载。
- 编号范围、作者年份式引用存在定位限制，定位失败显示明确提示。
- 本轮未重新验收 Word/DOCX、PPT 或论文装配其他功能。
