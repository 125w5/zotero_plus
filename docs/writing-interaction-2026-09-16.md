# 论文装配交互整改（2026-09-16）

本轮保留 Zotero 原生阅读器、现有文库和嘉立创式外层布局，未引入第二套编辑器、文献数据库或本地模型。

## 问题复现和修改

- 日常文库实际有 79 张素材。保存的查询与类型筛选组合曾把卡片筛空，而全文命中始终展开，造成只显示“方法与实验”的误解。现在显示可清除筛选，全文命中默认折叠，素材浏览与全文检索分开。
- 实际点击“论文结构”复现素材库选中颜色未更新。导航现在即时更新选中颜色和无障碍状态，固定在左栏顶部。默认宽度从 310 调到 380 像素，保留用户已调宽的设置。
- 素材保留“中文简述 / 题目·分类”切换；悬停显示中文说明，卡片悬停与键盘聚焦变暗。无 IF 和无指标年份不再占用列表，真实 IF 及投稿/发表区分保留。
- AI 共创采用独立滚动消息区、角色层次、固定底部输入框；收起保留输入行，聚焦展开，模板从输入上方浮出。草稿与讨论继续保存。
- 正文支持 Ctrl+B/I/U、Ctrl+Enter 光标分页、Ctrl+Z/Y、右键字体颜色和段落分页、页面空白双击插段落、素材下方继续写作。材料拖入按落点插入，垂直距离可形成一至两行段前间距，不再默认叠加到已有框。Ctrl+滚轮仅缩放纸张。右侧显示公式、表格和图片的实际预览。
- 创建页只要求名称，下一步进入可行性讨论，用户再进入装配。评估、修改记录、旧方案、接近文献与真实 IF（可用时）保留；预处理、防泄漏、公平基线、消融、鲁棒性、可靠性与复现条件纳入实验计划。
- 独立素材页“素材库”入口打开项目管理和全部素材浏览。联网入口在本地有结果时也可使用；公开论文按页加载，每页 20 篇，支持底部继续加载。元数据先行，全文按用户选择获取；验证 PDF 内容并复用已有条目/附件。
- 学术表达以真实同领域来源、术语定义、适用边界和论证为依据，不使用录用分数，不把期刊 IF 或生僻术语当作创新的证明。

## 性能修复

原 `store.get()` 每次都复制整个工作区，素材标题、说明及状态反复触发该读取。在包含约 22 MB 保存数据、1548 张验收素材的隔离环境中，出现数十秒等待。

新增按路径读取的隔离副本，卡片只复制所需说明/素材分支；连续保存合并为待保存的最新快照。保持原子写入、版本检查和资产隔离，不改变文库文件格式。

相同 Gecko 验收流程，创建阶段从 67.4 秒降至 2.5 秒，素材显示/筛选检查从 78.5 秒降至 1.1 秒。这是该验收环境的观测值，不是所有设备的性能保证。

## AI 共创补充整改与最终构建

用户反馈共创区视觉生硬后，在实际日常项目中复现了短消息横向拉满、输入栏比消息区宽得多的问题。消息与输入统一限制为 1020px，用户短消息随内容收宽；回答不再层层套框。顶部显示简短的当前段落上下文，收起时保留单行输入，聚焦展开。模板从输入上方浮出，Enter 发送、Shift+Enter 换行，中文组词期间不提交。

来源问答发送后立即显示问题与处理状态，期间禁用重复发送；成功后清除本次已发送的草稿，用户等待期间新输入的草稿保留。错误在输入附近显示，原输入可重试。修复收起后焦点未移出输入框时无法再次展开，以及保存通知覆盖当前正文对象详情的问题。

- 最终普通构建：`scripts/build-native.ps1 -Incremental` 成功，已通过 `scripts/launch-research.ps1` 启动日常配置；未替换为隔离测试文库。
- 日常真实前台：查看新版共创区；原有讨论恢复、素材总数 79。实际键盘验证 Ctrl+B 与 Ctrl+Z，清理了本轮输入的临时验收句子，保存后重启确认该句不在项目中。原公式、素材框和已有内容保留。
- 最终 Gecko 界面检查：7 项界面受控事件通过；另 1 项使用受控回复检查等待状态、重复发送保护、新草稿保留及中文表格公式渲染。两项真实服务测试在这次 UI 重测中跳过，不冒充重新调用。
- Node 相关检查：中文说明、写作选区与来源保护、分支存储共 9 项通过。
- 真人中文输入法、实际 Ctrl+滚轮组合、完整拖放、通用开放附件下载及 Microsoft Word 打开仍未全部验证。新版收起与模板操作有 Gecko 事件验证；日常桌面操作多次因用户切换前台而中断，不计为完整真人路径通过。
