# 阅读、组会与写作工作区验收（2026-10-19）

## 使用方式

- 阅读器默认显示底部输入栏，空闲时渐隐收回，接近后恢复。拖到左右侧后保留图标，点击进入同一段对话；侧栏关闭时图标停在阅读区边缘，打开时停在真实栏内，停图标不会自行展开侧栏。单击外部变暗、双击外部收起，固定后保留展开状态。模型、思考强度、任务和权限菜单挂在窗口浮层，避开输入栏裁切。
- 研究对话页面保持完整高度，不再嵌套一层需要点击展开的对话窗口。资料栏与详情栏使用一致的文字大小、边界和玻璃背景，保留搜索、勾选、精选、预览和拖放。
- 原生笔记的插入按钮放进编辑器现有工具栏，不另占一行；保留公式、表格、CSV/Excel 和图片插入。页外批注输入复用现有卡片与笔记关联索引，避免逐字重建布局或遍历全部关联。

## 组会 PPT

按“选择材料 → 选择模板 → 编辑大纲 → 图片与示意图 → 我的内容 → 逐页编辑与导出”组织工作。

- 选论文在当前页面内完成，支持搜索。左侧拖入论文、表格、图片、文本后实际进入本次汇报材料，不只是加入对话附件。
- 大纲支持编辑、增删、上下移动；“增加板块”创建可继续编辑的实际条目。
- AI 和模板调整先生成红色删除、绿色新增的结构提案；用户选择保留或撤回。保留后可撤销、重做，过期提案不能覆盖较新的结构。
- 调整结构时按稳定 ID 关联页面，保留人工内容、讲稿与配图。双图页面显示两张图，无图页面不虚构装饰流程图。
- 拖到编辑画布或指定缩略图的资料关联对应页；幻灯片排序使用独立拖放类型，避免把外部资料误认为排序操作。删除最后一页后再次新增仍可正常打开。

## 写作速读与正文

- 素材、写作速读、正文使用明确的模式切换。在后两种模式中，右侧为编辑对话，并可直接切回原详情栏。
- 正反方向选择文字均记录实际块与字符范围；素材选区在高亮清除前捕获，保留来源与原文锚点。
- AI 根据当前章节规则、结构计划、术语、准备材料和可行性要求提出局部候选。语言要求为客观、准确、连贯的学术表达，避免套话、营销式修饰与防御性措辞，同时保留事实、数值、引用和论断强度。
- 候选显示红绿差异并提供可选方案，显式采用后才保存。返回和采用前检查原文、计划、来源及锚点版本；撤回不能覆盖用户后续人工修改。批注仍走统一的原文同步路径。
- 对话草稿按会话保留，消息可拖动；采用和撤回按钮等待实际保存完成，防止看似可点却无响应。

## 翻译与检索

- 选区机翻支持 Azure Translator（密钥、区域），并兼容已有有道配置。“机翻”路径不会悄悄切为模型翻译。公式保护标记经过完整性检查。
- 整篇译文和素材翻译使用独立的低价模型配置，默认 `deepseek-flash`，与研究对话的 GPT-6 Luna 配置分开。无翻译密钥时显示配置提示，不自动改用研究对话模型。
- PDF 打开时开始同一项去重后台准备；译文视图读取本地逐页缓存，通知只刷新变化页，滚动不再次翻译或提取整篇图像。对照视图的首帧页边距与后加载样式保持相同，缩放后保留对应阅读位置。
- 论文搜集与推荐增加 Crossref、Europe PMC 的可下载开放 PDF 后备结果，保留来源、筛选条件、分页游标与服务失败原因。在线失败不清空已有及本地结果。
