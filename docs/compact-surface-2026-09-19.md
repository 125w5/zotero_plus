# 紧凑界面与首页预览验收（2026-09-19）

本轮修改现有 Zotero/EasySch 文库、工作台、素材筛选和论文创建入口。沿用中央标签页、原生 PDF 阅读器及原有数据，未创建另一套文献数据库。

## 已实现的入口与行为

- 文库选择论文或 PDF：右侧统一按“首页预览 → 摘要 → 信息”排列；工作台的文献阅读页共用首页预览组件。无本地 PDF 时明确显示原因，保留摘要和题录。
- “编辑完整信息”放在“信息”标题右侧。重复的附件预览收起，避免同一详情区再占一块空间。
- 首页预览内提供“图片证据”；点击复用原有阅读标签，等阅读器加载完再展开。重复进入保留现有面板，不因开关行为把面板关闭。
- 独立素材库和装配左栏的筛选、排序收进搜索框右侧浮层；全选与显示模式同行。保留原搜索输入节点，不通过重建输入框打断中文组词。
- 原生文库和工作台使用一致的灰色选中、悬停反馈与字体层级。原生文库左下标签筛选区替换为日期/待办入口；标签数据不删除。
- 日期入口只占一行，点击弹出月历。有待办的日期带标记，可查看并勾选当天任务。模型、翻译、期刊与模板从底部“⚙ 设置”进入。
- 标签末尾“+”打开页面菜单；标签右键增加“添加页面…”。非文献标签不再显示无意义的“在文库显示”，并修复无附件对象时的右键异常。
- 工作台文献阅读、文献搜集、论文装配使用可点击流程条。新建项目输入名称后可以“下一步：讨论可行性”，也可以“直接装配”；可行性方案和素材仍可随后补充。

### 尚未完成的真实前台检查

以下功能已通过原生测试，但本轮最后的鼠标验收受阻：输入名称并点击“直接装配”、素材库搜索内筛选与全选、标签右键。桌面工具连续返回 `user input was detected in this window`，恢复前台也被拒绝；用户表示暂停操作后重试仍被拒绝，已停止继续注入鼠标键盘事件。

- 月历“有任务的日期变色”和完成勾选通过隔离文库的原生测试；日常文库鼠标测试当天无任务，没有把空日历截图当作有任务状态验收。
- 本轮没有新的模型/联网测试。前台的 9 条图片证据复用此前真实 PDF/API 处理结果，没有将缓存复用报告为新生成。
- 已正常退出并重启日常程序，原论文与已有图片中文说明仍可读取。尚未完成本轮新建项目的真人重启恢复路径。
- 暗色主题规则已保留，本轮没有完成暗色模式的真实桌面复验。
- 本轮未更新发行安装包，未重新执行 Microsoft Word/DOCX 验收。
- 修改范围不包含所有原生系统对话框；没有宣称所有页面、所有按钮都完成统一。
