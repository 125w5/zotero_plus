# 研究工作区交互与性能验收（2026-10-16）

## 界面与资料工作流

- 新建对话和历史位于资料栏，不再置于原生主导航上方。文献搜集、推荐、研究对话、论文装配和组会 PPT 复用资料栏，支持搜索、筛选、勾选和精选。
- PPT 使用完整中心工作区；材料、汇报设置和编辑操作直接可用，窄窗口按顺序排列。初始化预留侧栏空间，避免异步加载后整体横移。功能保持可见，说明、原文和历史等次要信息按需展开。
- CLUI 保留输入、对话和内容查看三种尺寸。点击内容同时增宽增高，顶部整条拖动区可调整高度，支持键盘调整；单击外部变暗，双击外部收起，固定后保持展开。
- 搜索和推荐的论文可拖到某段对话中下载并关联；保存目标跟随项目或 PPT 文件夹。文件可继续拖到对话、装配位置或指定 PPT 页面，保留原文件、来源和人工内容。
- 历史回答拖入另一段对话后保存为引用资料，不自动发送新任务。异步下载和读取始终使用发起时的会话及页面身份，避免切换后放错位置。
- 右栏提供论文信息、摘要、图片和线索，以及表格、文本等文件预览；不嵌入第二个 PDF 阅读器。装配保留章节范文的明确选择。

## 性能处理

- 对话服务缓存归一化结果和会话索引，按数据分支版本失效。列表和订阅支持元数据视图，保留当前会话完整内容，其余不复制历史消息。
- 保存草稿不再携带完整消息；对话写入只复制对应分支，不触发全部论文项目扫描和来源刷新。旧的通用写入接口仍保持兼容。
- 研究对话与装配保留未变化的消息节点，缓存最近四段对话的 DOM 和滚动位置，淘汰时释放图片、拖动和媒体事件。
- PPT 和装配跳过无关会话通知；资料列表、历史及文件预览独立更新。给资料打星、保存草稿不会重新打开正在查看的文件。
- 资料读取使用附件专用 API，不再为了读取附件而复制整段会话。快速切换取消过期请求，草稿按原会话保存。
- Excel 按路径、文件大小、修改时间和 Python 配置缓存并合并同版本并发解析。最多保留八项、约 8 MiB；每次返回独立副本。删除、变更和解析失败均不会使用旧结果。
- 装配焦点重验合并并发，关闭页面移除监听并停止后续检查。

控制基准使用 100 个项目（每项目 30 个正文块）及 100 段对话（每段 20 条消息），连续执行 20 次选择。复制及订阅 CPU 时间从 655.4 ms 降至 76.3 ms；包含完整持久化 JSON 序列化为 895.2 ms → 284.4 ms；全部项目扫描 40 次 → 0 次。基准不包含真实磁盘延迟，不能解释为整应用或模型推理速度。持久化仍使用原有单一 JSON 文件，未更换数据格式。
