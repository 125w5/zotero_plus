# 导入后自动整理图片证据（2026-09-18）

本轮范围：PDF 阅读器中的图片提取、中文解释、素材入库及导入后的自动运行。保留原生阅读器与现有研究资产，不新增应用、不下载模型。

## 使用入口

导入 PDF 后，无需点“分析”。本地添加文件、拖放、附加 PDF 和下载保存共用附件 add/modify 通知，分别启动文字素材与图片证据任务。图片先入库，说明随后逐张更新。

阅读器右侧 **学术对话 → 关联证据与论文图表 → 图片证据与中文解读** 显示原图、中文概括、完整解读及回到原图。重新解读、调整裁切、保存笔记与 PPT 选择收进“更多”。打开面板也会为旧论文补建图片证据。

## 数据与行为

- 图片按文件 SHA-256、页码、裁切位置保持稳定 ID，提取与分析分别带版本。
- 同文件的多个附件共享素材，保留各附件来源锚点；图像坐标转换为阅读器的 PDF 坐标。
- 自动入库不加入 PPT 素材盘。已入库图像受保护，清理自动缓存不会删除它们。
- 完整图片、图注和相关正文通过现有 API 发送。API 明确不支持图片时才降为图注/正文解释，界面标明“未读取图片像素”；鉴权、额度、网络失败不能假装完成。
- 说明失败时保留图片与已完成说明；只重试未完成项。并发同附件合并为一个任务，来源在处理中变化时追加一次检查。
- 用户编辑或确认的说明不被自动替换；响应写入前检查素材版本。自动更新保留说明历史。
- 退出时停止任务，未完成任务保留为可恢复状态。任务进度使用独立通知，避免每个进度更新都重绘整个素材库。

## 边界与尚未验证的项目

- 自动处理对象是 PDF 附件；本轮没有添加 DOCX 内嵌图片导入。
- 扫描 PDF 没有可识别图注或独立图形时，不能保证自动拆出每张图。复杂多子图仍应核对裁切，可从完整页面重新框选。
- AI 解读始终标为待核验。已验证 API 接收真实图片并返回中文解读，不把此测试当作对所有图中数值和科学结论正确性的保证。
- 拖放、下载附件与为已有条目附加 PDF 复用相同通知路径，但本轮未逐个完成真实鼠标验收。
- 本轮完成本机程序构建并启动；未重新生成发行安装包，也未进行与本轮无关的 Word 验收。
