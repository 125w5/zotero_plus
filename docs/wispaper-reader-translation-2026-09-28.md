# 阅读器译文与公式验收（2026-09-28）

本轮在现有 EasySch/Zotero 单程序内改进阅读器，不引入第二个 PDF 阅读器或本地模型。实际启动 WisPaper 观察了“论文 / 译文”切换、缩略图、原文与译文并排的交互；未复制 WisPaper 程序文件、源码或素材。

## 已实现

- Zotero 原生 PDF 标签增加“译文”入口。在同一标签内，左侧保留可操作的原 PDF，右侧显示同页尺寸的白色译文纸页。中文框按原文段落坐标放在右页对应位置，尺寸随原文区域变化，长内容在框内滚动。翻页、缩放和滚动联动；关闭译文后恢复原 PDF 阅读宽度。
- 公式和编号不送入机器翻译。右页优先放入来自 PDF 的原式图；图片暂不可用时提示核对左页原式，不以杜撰的公式代替。
- 已配置机翻时优先用快速机翻；否则使用 API-only 的 GPT-6 Luna。对第三方 OpenAI 兼容网关，明确使用流式响应并校验结果完整性。用户给出的站点根地址自动规范为 `/v1`。
- 素材库可生成概念示意图。图像以“AI 构想 / 非论文证据”入库，不当作真实论文或实验结果。AI 与图像凭据分别存于本机 Zotero 密码管理器；代码与 Git 提交不包含密钥。

## 验证类型

- **真实 Zotero 前台 + 真实模型（改版前基线）：** 在隔离验收文库打开 C-AMC PDF，第 3 页侧栏曾显示 9/9 处中文正文；第 5 页曾显示中文段落及原式图片。用户要求改为 PDF 原位框，因此此项不能作为新版 UI 的通过证据。图像生成入口在前台生成并入库一张构想素材，数量从 1610 增至 1611，状态明确为“非论文证据”。
- **真实 API：** GPT-6 Luna 网关返回中文与结构化 JSON；图像网关返回可读取 PNG。该调用与受控回复测试分开记录。
- **原生自动测试（改版前基线）：** `researchReaderInteraction` 15 项通过，包含实际 PDF 阅读器实例、受控双栏/公式顺序和慢图片索引；这组结果不代表新版左右对照纸页已通过。`chat-completion` 4 项、`image-generation` 8 项通过，底层调用在本轮未改。
- **尚需前台复查：** 左原 PDF 与右译文页的版式、缩放/翻页/滚动联动、公式图，以及图片放大/笔记新交互，仍待新版构建与真实鼠标验收。此前桌面工具检测到正在进行的输入而拒绝继续操作，不能把旧侧栏的验收结果算作新版通过。

## 限制

公式识别依赖 PDF 文字提取与图片索引；扫描页需 OCR，长公式及行内混排公式仍可能需要人工核对。缺少可靠位置的段落不强行放入右页，以免错配。机器翻译用于阅读辅助，不等同出版级学术译稿。本版工作区改动保持未提交。
